# 🛒 FoodMart – Online Grocery Shopping Website

**FoodMart** is a modern and responsive online grocery shopping website designed to provide users with a simple and convenient way to browse grocery products, add items to their cart, and complete the checkout process.

The project focuses on creating a realistic e-commerce experience with a clean user interface and user-friendly shopping flow.

## ✨ Features

* 🏠 Attractive Home Page
* 🛍️ Browse grocery products
* 🔎 Product search and filtering
* 🛒 Add products to cart
* ➕ Increase/decrease product quantity
* 💰 Automatic cart total calculation
* 📦 Checkout page
* 💳 Multiple payment-method UI
* 👤 User-friendly interface
* 📱 Responsive design for mobile and desktop
* 🎨 Clean and modern UI
* ⚡ Interactive JavaScript functionality

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd FoodMart
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows:**

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run migrations

```bash
python manage.py migrate
```

### 7. Start the Django server

```bash
python manage.py runserver
```

Open:

```text
http://127.0.0.1:8000/
```
